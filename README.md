## Projetos em destaque

### VisionX Neural
Sistema de inspeção óptica automatizada (AOI) baseado em IA para análise de placas eletrônicas em ambiente industrial.

### SIGMA-Q
Plataforma de qualidade industrial para análise de defeitos, PPM, FMEA e diagnóstico inteligente.

### Skill Map
Sistema de gestão de operadores, skills, assiduidade e tomada de decisão apoiada por IA.

### LumusPCI
Sistema de visão computacional para inspeção automática de LEDs em placas PCI.

### Central de Aprovações (CA)
Plataforma corporativa para registro, armazenamento e consulta de aprovações técnicas e documentação fotográfica.
